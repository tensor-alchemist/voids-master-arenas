How to use this tool This tool can't write directly into Doom: The Dark Ages — id Software's in-game systems aren't something we can reach into or automate from outside the game. Once you've generated an arena you like, open your own Ripatorium Arena builder and enter the Global Settings and per-round demon counts shown below by hand (or hit Copy Setup to grab a plain-text checklist). Every number this tool produces already respects the exact min/max/step limits of the in-game sliders, so nothing you see here will be a value the game refuses.
