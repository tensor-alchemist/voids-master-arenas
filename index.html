How to use this tool Each round card shows an In-game passcode — click it to copy, then paste it into the Ripatorium's passcode field and the game sets every demon slider for that round automatically (we reverse-engineered id Software's passcode format to make this work). Global Settings and Wave Respawns still need entering by hand — they aren't part of id's passcode — or hit Copy Setup for a plain-text checklist. Every number this tool produces already respects the exact min/max/step limits of the in-game sliders.

Only have a few minutes? Set Time Limit Mode to Fixed, pick your time, and the generator will build a fight sized to be beatable inside that window. If you don't own the DLC, switch Content Pool to Base Game Only. Your settings and last campaign are remembered between visits, and pressing R rerolls the horde. Rolled something brutal? Copy Link grabs a shareable URL — anyone opening it gets your exact campaign, passcode and all.
